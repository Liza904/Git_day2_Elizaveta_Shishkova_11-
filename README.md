# Git_day2_Elizaveta_Shishkova_11-tes26
Git — это система управления версиями, которая позволяет разработчикам отслеживать изменения в коде, работать над проектами совместно и сохранять историю изменений

1. Что такое Git?
```
Git- это система управления версиями,которая помогает разработчикам отслеживать изменения в коде, работать над проектами
````
2 Для чего нужен Git?
```
используется для контроля изменений в коде, совместной работы над проектами
```
3 За что отвечает команда git status?
```
команда git status показывает текущее состояние репозитория: какие файлы изменены, какие готовы к коммиту, какие находятся в других ветках
```
 4 За что отвечает команда git imit?
 ```
Команда git init создает новый репозиторий Git в текущей директории
```
 5 За что отвечает команда git add
 ```
Команда git add добавляет файлы в индекс
```
 6 За что отвечает команда git commit?
 ```
  Команда git commit сохраняет изменения в историю репозитория
```
 7 Зачем необходимо комментировать коммиты?
```
Это помогает понять, что было изменено, зачем и кем. Это упрощает работу
```
